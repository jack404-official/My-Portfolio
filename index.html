01 / SOFTWARE & HARDWARE

BSOD Error

Laptop ini sebelumnya berjalan normal, tetapi setelah dilakukan install ulang, tiba-tiba mengalami BSOD dengan error code ETD.sys dan MEMORY MANAGEMENT. Hal tersebut biasanya terjadi karena driver pada touchpad mengalami konflik atau tidak kompatibel dengan sistem. Untuk mengatasi masalah tersebut, saya mencoba menyembunyikan update driver touchpad dari Windows Update agar driver yang bermasalah tidak terpasang kembali. Sementara itu, untuk error MEMORY MANAGEMENT, saya menjalankan Memory Diagnostic untuk memeriksa dan membantu mengatasi masalah pada blue screen tersebut.
