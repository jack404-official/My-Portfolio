01 / SOFTWARE & HARDWARE

BSOD Error

This laptop was running fine until a system reinstall suddenly triggered a BSOD with the error codes ETD.sys and MEMORY MANAGEMENT. That usually happens when the touchpad driver conflicts with the system or isn't compatible with it. To fix it, I hid the touchpad driver update from Windows Update so the faulty driver wouldn't get installed again. For the MEMORY MANAGEMENT error, I ran the Memory Diagnostic tool to check and help resolve the blue screen issue.
